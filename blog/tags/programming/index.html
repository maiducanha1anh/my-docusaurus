A Guide to Building a Personal Blog with Docusaurus

January 22, 2026 · One min read
Mai Duc Anh
Blogger & Developer

In this post, I will walk through the detailed steps for creating a personal blog using Docusaurus – a powerful framework for building documentation websites and static blogs.

This post is intended for:

  • IT students
  • Web development beginners
  • Anyone who wants a professional personal blog

2. What is Docusaurus?​

Docusaurus is an open-source framework developed by Facebook, designed for creating:

  • Personal blogs
  • Documentation websites
  • Project showcase websites

Key advantages:

  • Free and open-source
  • Easy to use
  • Write content in Markdown
  • Straightforward deployment to GitHub Pages

3. Environment Setup​

Prerequisites:

  • Node.js (version >= 18)
  • npm (bundled with Node.js)

Verify your installation with:

node -v
npm -v
