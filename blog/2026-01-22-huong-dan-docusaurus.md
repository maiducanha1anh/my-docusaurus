# Đây là bài blog đầu tiên của mình viết bằng Docusaurus.

Trong bài viết này, mình sẽ hướng dẫn chi tiết cách tạo một blog cá nhân bằng **Docusaurus** – một công cụ rất mạnh để xây dựng website tài liệu và blog tĩnh.

Bài viết phù hợp cho:
- Sinh viên IT  
- Người mới học web  
- Người muốn có blog cá nhân chuyên nghiệp  

---

## 1. Docusaurus là gì?

Docusaurus là một framework mã nguồn mở do Facebook phát triển, dùng để tạo:
- Blog cá nhân  
- Website tài liệu  
- Website giới thiệu dự án  

Ưu điểm:
- Miễn phí  
- Dễ dùng  
- Viết bài bằng Markdown  
- Deploy dễ lên GitHub Pages  

---

## 2. Chuẩn bị môi trường

Bạn cần cài sẵn:

- Node.js (phiên bản >= 18)
- npm (đi kèm Node.js)

Kiểm tra bằng lệnh:

```bash
node -v
npm -v
```
