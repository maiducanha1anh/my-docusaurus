Chủ đề: Prefix Sum 1D & 2D
Tổng số bài đã làm: 4

I. LÝ THUYẾT​

1. Định nghĩa (Definition)​

Prefix Sum (mảng cộng dồn) là: Một cách lưu trước tổng các phần tử từ đầu đến vị trí i

Prefix Sum 1D là prefix sum áp dụng cho mảng 1 chiều
prefix[i] = tổng từ đầu → i

a      = [1, 3, 5, 2, 4]
prefix = [1, 4, 9, 11, 15]

Prefix Sum 2D là prefix sum áp dụng cho ma trận (2 chiều)
prefix[i][j] = tổng từ (0,0) → (i,j)

a = 1 2    →    prefix = 1 3
    3 4                  4 10

2. Ý tưởng cốt lõi (Core Idea)​

Bản chất: Biến việc tính tổng nhiều lần → thành tính trước 1 lần

Prefix Sum 1D

  • Lưu tổng từ đầu → i
  • Giúp tính nhanh tổng đoạn [l → r]

Prefix Sum 2D

  • Lưu tổng từ (0,0) → (i,j)
  • Giúp tính nhanh tổng 1 vùng hình chữ nhật

3. Khi nào áp dụng (When to Use)​

Dấu hiệu nhận biết: Nếu thấy tính tổng lặp đi lặp lại nhiều lần → nghĩ ngay Prefix Sum

Bài có dạng:

  • "Tính tổng từ l → r"
  • "Tính tổng nhiều đoạn"
  • "Tính tổng vùng trong ma trận"
  • Có nhiều truy vấn (queries)

Pattern liên quan:

1D2D
Subarray sumSum of submatrix
Range sum queryBài toán grid / map / ảnh
Tìm đoạn có tổng = kGame map, heatmap

4. Độ phức tạp (Complexity)​

Prefix 1DPrefix 2D
BuildO(n)O(n × m)
QueryO(1)O(1)
SpaceO(n)O(n × m)

5. Lỗi thường gặp (Common Pitfalls)​

  • Nhầm chiều i, j: i = hàng, j = cột
  • Không hiểu bản chất 2D:
    • ❌ Nghĩ: prefix[i][j] là 1 ô
    • ✅ Thực tế: là 1 vùng
  • Sai công thức 1D

II. BÀI TẬP​

Bài 1: Running Sum of 1d Array​

Running Sum of 1d Array - LeetCode

1. Tóm tắt đề bài (Problem Summary)​

  • Cho một mảng số nguyên nums
  • Tạo một mảng mới (hoặc sửa luôn mảng cũ) sao cho mỗi phần tử tại vị trí i = tổng tất cả phần tử từ đầu đến i

2. Hướng tiếp cận (Approach)​

  • Lý do chọn cách giải:
    • Duyệt mảng từ trái sang phải
    • Lưu lại tổng cộng dồn trước đó
    • Mỗi bước chỉ cần cộng thêm phần tử hiện tại
    • Dùng mảng res để lưu kết quả trung gian
  • Pattern áp dụng: Prefix Sum 1D (Cộng dồn mảng 1 chiều)
    res[i] = res[i-1] + nums[i]
  • Liên hệ lý thuyết: Thuộc chủ đề Prefix Sum trong DSA — tái sử dụng kết quả trước đó để giảm độ phức tạp

3. Ý tưởng giải (Solution Idea)​

  1. Tạo mảng res cùng kích thước với nums
  2. Gán res[0] = nums[0]
  3. Duyệt từ i = 1 → n-1: res[i] = res[i-1] + nums[i]
  4. Trả về res

4. Code​

def runningSum(nums):
    res = [0] * len(nums)
    res[0] = nums[0]
    for i in range(1, len(nums)):
        res[i] = res[i-1] + nums[i]
    return res

5. Độ phức tạp (Complexity)​

  • Time Complexity: O(n) — duyệt mảng 1 lần
  • Space Complexity: O(n) — dùng thêm mảng res

6. Bài học rút ra (Key Learning)​

  • Insight: Khi bài toán có dạng "tổng từ đầu đến i" → nghĩ ngay đến Prefix Sum
  • Pattern reuse: Tính tổng đoạn [l, r], đếm số subarray có tổng bằng k
  • Lưu ý:
    • Phải xử lý riêng phần tử đầu res[0]
    • Cẩn thận với index (i-1)

Bài 2: Subarray Sum Equals K​

Subarray Sum Equals K - LeetCode

1. Tóm tắt đề bài (Problem Summary)​

Cho một mảng số nguyên nums và một số nguyên k. Hãy đếm số mảng con (liên tiếp) có tổng bằng k.

2. Hướng tiếp cận (Approach)​

  • Lý do chọn cách giải:
    • Duyệt toàn bộ mảng con → O(n²) chậm
    • Cần tối ưu xuống O(n): dùng Prefix Sum + HashMap để tránh tính lại
  • Pattern áp dụng: Prefix Sum + HashMap
  • Liên hệ lý thuyết: Thuộc chủ đề Prefix Sum trong DSA

3. Ý tưởng giải (Solution Idea)​

  1. Duyệt mảng từ trái sang phải, tính tổng cộng dồn currentSum
  2. Dùng HashMap để lưu prefixSum: số lần xuất hiện
  3. Tại mỗi bước: kiểm tra currentSum - k có trong map không?
  4. Nếu có → cộng số lượng vào kết quả
  5. Cập nhật map

4. Code​

def subarraySum(nums, k):
    count = 0
    currentSum = 0
    hashmap = {0: 1}

    for num in nums:
        currentSum += num
        if currentSum - k in hashmap:
            count += hashmap[currentSum - k]
        hashmap[currentSum] = hashmap.get(currentSum, 0) + 1

    return count

5. Độ phức tạp (Complexity)​

  • Time Complexity: O(n) — duyệt mảng 1 lần
  • Space Complexity: O(n) — lưu HashMap

6. Bài học rút ra (Key Learning)​

  • Insight: Khi gặp "subarray có tổng = k" → nghĩ ngay: Prefix Sum + HashMap
  • Pattern reuse: Áp dụng lại cho Subarray Sum = k
  • Lưu ý:
    • Phải có {0: 1} khởi tạo trong map
    • Mảng có thể có số âm
    • HashMap lưu số lần xuất hiện, không phải chỉ boolean

Bài 3: Range Sum Query 2D - Immutable​

Range Sum Query 2D - Immutable - LeetCode

1. Tóm tắt đề bài (Problem Summary)​

Cho một ma trận 2D, xử lý nhiều truy vấn: tính tổng các phần tử bên trong hình chữ nhật được xác định bởi góc trên trái (row1, col1) và góc dưới phải (row2, col2).

2. Hướng tiếp cận (Approach)​

  • Lý do chọn cách giải:
    • Nếu mỗi lần query tính lại → O(m × n) rất chậm
    • Có nhiều query → cần tối ưu
    • Dùng Prefix Sum 2D: tính trước 1 lần, query nhanh O(1)
  • Pattern áp dụng: Prefix Sum 2D
  • Liên hệ lý thuyết: Prefix Sum 1D, Prefix Sum 2D

3. Ý tưởng giải (Solution Idea)​

  1. Tiền xử lý: Tạo mảng dp kích thước (m+1) x (n+1), dp[i][j] lưu tổng từ (0,0) → (i-1, j-1)
  2. Trả lời query — áp dụng công thức:
sum = dp[row2+1][col2+1]
    - dp[row1][col2+1]
    - dp[row2+1][col1]
    + dp[row1][col1]

4. Code​

class NumMatrix:
    def __init__(self, matrix):
        m, n = len(matrix), len(matrix[0])
        self.prefix = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                self.prefix[i][j] = (matrix[i-1][j-1]
                                   + self.prefix[i-1][j]
                                   + self.prefix[i][j-1]
                                   - self.prefix[i-1][j-1])

    def sumRegion(self, row1, col1, row2, col2):
        p = self.prefix
        return (p[row2+1][col2+1]
              - p[row1][col2+1]
              - p[row2+1][col1]
              + p[row1][col1])

5. Độ phức tạp (Complexity)​

  • Time Complexity: O(1) per query
  • Space Complexity: O(m × n)

6. Bài học rút ra (Key Learning)​

  • Insight: Khi thấy "nhiều truy vấn" + "tính tổng vùng" → nghĩ ngay: Prefix Sum
  • Pattern reuse: Range Sum Query 1D / 2D, Image processing (tính vùng)
  • Lưu ý: Phải dùng mảng (m+1) x (n+1) để tránh lỗi index

Bài 4: 연속된 부분 수열의 합 (Tổng của dãy con liên tiếp)​

코딩테스트 연습 - Programmers

1. Tóm tắt đề bài (Problem Summary)​

  • Cho một dãy số đã được sắp xếp tăng dần và một số k
  • Tìm đoạn liên tiếp có tổng đúng bằng k
  • Nếu có nhiều đoạn thỏa mãn: chọn đoạn ngắn nhất; nếu vẫn có nhiều → chọn đoạn xuất hiện sớm nhất (index nhỏ hơn)
  • Trả về [vị trí bắt đầu, vị trí kết thúc]

2. Hướng tiếp cận (Approach)​

  • Lý do chọn cách giải:
    • Duyệt toàn bộ → O(n²) chậm
    • Mảng toàn số dương + đã sort → dùng được Sliding Window
  • Pattern áp dụng: Sliding Window / Two Pointers
  • Liên hệ lý thuyết:
    • Mảng toàn số dương, cần tìm subarray có tổng = k
    • Dùng 2 con trỏ left, right để tăng/giảm cửa sổ điều chỉnh tổng

3. Ý tưởng giải (Solution Idea)​

  1. Dùng 2 con trỏ: left = 0, right = 0, duy trì currentSum
  2. Luật di chuyển:
    • currentSum < k → mở rộng (right++)
    • currentSum > k → thu nhỏ (left++)
    • currentSum == k → cập nhật kết quả nếu tốt hơn, sau đó dịch left để tìm đoạn ngắn hơn
  3. So sánh kết quả theo thứ tự ưu tiên: 1. độ dài nhỏ hơn, 2. nếu bằng → left nhỏ hơn

4. Code​

def solution(sequence, k):
    left, right = 0, 0
    current_sum = sequence[0]
    result = [0, len(sequence) - 1]

    while right < len(sequence):
        if current_sum == k:
            if (right - left) < (result[1] - result[0]):
                result = [left, right]
            current_sum -= sequence[left]
            left += 1
        elif current_sum < k:
            right += 1
            if right < len(sequence):
                current_sum += sequence[right]
        else:
            current_sum -= sequence[left]
            left += 1

    return result

5. Độ phức tạp (Complexity)​

  • Time Complexity: O(n)
  • Space Complexity: O(1)

6. Bài học rút ra (Key Learning)​

  • Insight: Tất cả số đều dương → tổng luôn tăng khi mở rộng → dùng được Sliding Window
  • Pattern reuse: Subarray sum = k (all positive), Longest/Shortest subarray
  • Lưu ý:
    • Chỉ dùng Sliding Window khi không có số âm
    • Nếu có số âm → phải dùng Prefix Sum + HashMap
